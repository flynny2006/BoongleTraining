# BoongleTraining
BoongleTraining is a fully from scratch made AI model training software

Train AI models **ultra-fast**. Often up to **50x** faster than normal training.
Train AI models with our training interface or python framework.

# How To Get Started
You can get started from scratch to make your own models **OR** use premade models **OR** open-source models.
We currently support the following open-source models:
- **qwen2.5:7b**: Qwen 2.5 with 7B parameters, expandable.
- **qwen2.5:14b**: Qwen 2.5 with 14B parameters, expandable.
- **glm-4.7-flash**: GLM 4.7 Flash, expandable.
- **kimi-k2.5**: Kimi K2.5, expandable.
- **boongle-1.6-flash** Our own Boongle 1.6 Flash model with 437B parameters and fully expandable.
